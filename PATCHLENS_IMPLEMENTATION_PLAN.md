# PatchLens AI — Chỉ mục triển khai

> Cập nhật: 2026-08-10
> Trạng thái: source R0–R7, workspace gate và clean-copy frozen install đã hoàn tất; release còn theo dõi bằng task mở.

Tài liệu này giữ đường dẫn tương thích cho đặc tả triển khai cũ. Nguồn sự thật hiện tại:

- [`ROADMAP.md`](./ROADMAP.md) — milestone, trạng thái, rủi ro và thứ tự thực thi.
- [`TASKS.md`](./TASKS.md) — backlog có ID, mức ưu tiên và Definition of Done.
- [`docs/protocol.md`](./docs/protocol.md) — protocol, message và compatibility contract.
- [`docs/security.md`](./docs/security.md) — trust boundary, dữ liệu nhạy cảm và quyền ghi.
- [`docs/quickstart.md`](./docs/quickstart.md) — luồng cài đặt và chạy React + Vite.
- [`docs/adr/`](./docs/adr/) — quyết định kiến trúc đã chốt.
- [`docs/spikes/`](./docs/spikes/) — nghiên cứu Next.js, cross-origin và persistence.

Tài liệu bổ trợ:

- [`docs/COMPETITIVE_LANDSCAPE.md`](./docs/COMPETITIVE_LANDSCAPE.md) — định vị sản phẩm, đối chiếu nhóm công cụ và guardrail cạnh tranh.

Không duy trì thêm backlog hoặc trạng thái release trong file này để tránh lệch với `ROADMAP.md` và `TASKS.md`. Thiết kế lịch sử vẫn còn trong Git history và merge parent.
